# 3 Análisis de Correlaciones — Dataset Impacto Redes Sociales

## Objetivo

Analizar relaciones entre variables numéricas para identificar patrones de comportamiento, indicadores de riesgo y asociaciones entre uso de redes sociales, hábitos de sueño y salud mental.

Todo el análisis debe generarse dentro de:

`social_impact_analysis.ipynb`

---

# Análisis de Correlaciones

## 1. Relaciones entre variables

Explorar relaciones entre variables numéricas para identificar:

* correlaciones positivas y negativas
* patrones relevantes de comportamiento
* posibles indicadores de riesgo
* asociaciones vinculadas al bienestar estudiantil

Variables principales:

* `Avg_Daily_Usage_Hours`
* `Sleep_Hours_Per_Night`
* `Mental_Health_Score`

---

## 2. Relaciones clave

Priorizar el análisis de relaciones entre:

* uso de redes sociales y salud mental
* uso de redes sociales y hábitos de sueño
* sueño y salud mental

El agente debe identificar:

* tendencias relevantes
* relaciones consistentes
* posibles patrones críticos

---

## 3. Análisis por subgrupos

Comparar correlaciones agrupadas por:

* `Gender`
* `Most_Used_Platform`

El análisis debe enfocarse en:

* diferencias de comportamiento
* variaciones entre grupos
* segmentos con posibles indicadores de riesgo

---

## 4. Interpretación de correlaciones

Interpretar correlaciones utilizando:

* `|r| > 0.7` → Muy fuerte
* `|r| > 0.5` → Fuerte
* `|r| > 0.3` → Moderada
* `|r| < 0.3` → Débil

Si se detectan correlaciones negativas relevantes entre uso digital, sueño o salud mental, el agente debe generar alertas interpretativas y destacar posibles implicaciones sobre bienestar estudiantil.

---

## 5. Exploración visual

Utilizar visualizaciones analíticas como:

* heatmaps correlacionales
* scatter plots con tendencia
* comparaciones visuales por subgrupos

Las visualizaciones deben facilitar la interpretación de relaciones y patrones relevantes.

---

## 6. Insights principales

Generar entre 4 y 6 insights automáticos basados en las relaciones encontradas.

Cada insight debe incluir:

* observación
* evidencia cuantitativa
* interpretación contextual

---

# Resultado Esperado

El análisis debe generar:

* correlaciones relevantes
* patrones de comportamiento
* alertas interpretativas
* visualizaciones analíticas
* insights contextualizados
